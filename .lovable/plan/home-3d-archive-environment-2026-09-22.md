# Home 3D Archive Environment

## Direction
Create an original home-only 3D environment mixing a digital reliquary with a decaying desktop. It will preserve the existing haunted palette, typography, Home photograph, page content, and all inner pages.

## Build
- Add a full-bleed procedural 3D layer behind the Home introduction using translucent archival panes, aged monitor/window frames, wire structures, dust motes, and restrained CRT light.
- Give the objects slow independent drift and subtle pointer-responsive depth, with reduced-motion support.
- Keep the name and links fully readable above the scene and preserve the existing scroll into featured projects.
- Use only code-built abstract geometry and existing non-AI photography; add no generated imagery or copied artwork.
- Remove the old generic floating background from the Home page where the new scene replaces it, without changing About, Projects, or Contact.

## Technical details
- Use React Three Fiber compatible with the current React 18 setup.
- Cap rendering resolution for mobile performance and avoid remote 3D assets.
- Verify the scene on desktop and mobile, including motion, links, readability, console output, and deployment-safe assets.
